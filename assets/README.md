Обложка приветствия:
- `welcome.png` — картинка (сейчас крокодил Coinplay). Работает, пока нет видео.
- Если положить `welcome.mp4` (до 20 МБ) или задать `WELCOME_VIDEO`, видео будет использоваться вместо картинки.
- Можно не класть файлы в репозиторий: отправьте боту фото или видео с аккаунта из `ADMIN_IDS`, и бот сохранит его как обложку.
